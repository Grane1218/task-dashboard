# 任务面板 · Task Dashboard

使用 React 18 + TypeScript（严格模式）+ Tailwind CSS + Zustand 构建的单页任务看板应用。

## 功能特性

- 三列看板（待处理 / 进行中 / 已完成），支持基于 @dnd-kit 的拖拽排序与状态切换（筛选状态下排序不错位）
- 任务增删改查：新建/编辑弹窗、删除二次确认 + 5 秒内可撤销、操作 Toast 提示
- 重复任务：每天/每周/每月自动生成下一周期任务（日期顺延，支持月末截断）
- 任务归档：归档到「已归档」区，不参与统计与提醒，可随时恢复
- 日历视图：月历展示任务（按截止/开始日归位），点击空白日期快速新建（预填当天）、点击任务直接编辑
- 番茄钟专注：任务卡片一键开始 15/25/45 分钟专注，支持暂停/继续/结束，完成时系统通知并可一键标记任务完成（刷新页面计时不丢）
- 键盘快捷键：N 新建、/ 搜索、1-4 切换视图、D 切换深浅色、? 查看帮助
- 组合筛选与搜索：按标题模糊搜索，按优先级、状态筛选
- 未完成任务定时提醒系统：桌面通知 + 应用内横幅，支持频率/时间/静默时段设置（每日/每周/每月按自然周期判定）
- 每日习惯：勾选完成、连续天数、补记历史日期、归档暂停（保留完成记录）
- 统计视图：任务状态分布、近 7 天完成趋势、习惯 12 周热力图与本周完成率
- 数据导出/导入备份（JSON，含任务、习惯与全部设置；导入时**弹窗选择方式**：合并导入保留现有数据仅追加新增项，覆盖导入整体替换并二次确认，提醒设置与主题仅随覆盖导入改变）
- 启动时每日一次的未完成清单弹窗（支持「今天不再提醒」）
- 响应式布局（移动端折叠为列表）与深色/浅色模式
- 弹窗统一支持 ESC 关闭、焦点管理与无障碍语义

## 启动命令

\`\`\`bash
npm install
npm run dev       # 启动开发服务器
npm run build     # 类型检查 + 生产构建
npm run preview   # 预览生产构建
\`\`\`

## 目录结构

\`\`\`
src/
  components/   # UI 组件
  store/        # Zustand 状态（任务 + 提醒 + Toast）
  types/        # TypeScript 类型定义
  utils/        # notificationHelper / reminderScheduler / date / filter
  hooks/        # useReminder（轮询逻辑封装）
\`\`\`

> 提醒系统说明：应用每分钟轮询一次；「每日/每周/每月」按自然日、自然周（周一为起点）、自然月判定，同一周期内只触发一次（防重复）；
> 页面从后台切回前台（visibilitychange）时会立即补检一次。
